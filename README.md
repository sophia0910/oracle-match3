# 甲骨消消乐

一款用甲骨文做的三消识字小游戏：消字形、认字卡、读卜辞。当前版本「二十五契七十五字」，每一契约两分钟一局。

**在线试玩（手机可直接打开）**：<https://sophia0910.github.io/oracle-match3/>

朋友只需要这个网址。之后每次更新推送上来，GitHub Pages 会自动重新构建，朋友刷新页面就是最新版，不用再发新链接。

## 玩法

- 8×8 棋盘，上下或左右交换相邻两块，三连即消；四连、五连有倍率。
- 每契有目标字与目标步数，消够目标字即「成文」，解锁字卡与卜辞。
- 首页点阵是进度；左右滑动或点箭头可以翻看已开的契。
- 另有「快契」：90 秒内凑够一个字，练手用。
- 分享挑战：微信小游戏内可生成带关卡与步数的挑战卡片。

## 本地运行

浏览器：仓库根目录直接 `python3 -m http.server 8765`，打开 `http://localhost:8765/`。`index.html` 是纯静态页面，没有构建步骤。

微信小游戏：用微信开发者工具「导入项目」选择本目录即可。`project.config.json` 里的 `appid` 目前是 `touristappid`，要真机预览 / 上传体验版，需要换成自己的小游戏 AppID。

## 部署

`main` 分支根目录即站点根目录。推送后 GitHub Pages 自动构建：

```bash
git add <file>
git commit -m "..."
GIT_CONFIG_GLOBAL=/dev/null GIT_TERMINAL_PROMPT=0 git push origin HEAD
```

构建状态可查 `gh api repos/sophia0910/oracle-match3/pages/builds/latest --jq .status`，显示 `built` 即已上线。页面没有 Service Worker，不做激进离线缓存，所以更新后朋友刷新就能看到新版。

## 素材与字源

- 前 30 字的甲骨字形为内置矢量拓影：28 个字形中，26 个的轮廓取自《趣味的甲骨金文》拓影，「山」「火」取自汉典《甲骨文编》甲骨文字形。
- 后 45 字（星、风、雷、泉、谷、丘、马、犬、豕、耳、心、首、舟、弓、车、虎、鹿、兔、龟、贝、角、女、子、立、门、衣、刀、戈、鼎、玉、夕、晶、气、象、燕、虫、齿、眉、自、尊、爵、壶、网、册、帚）的甲骨文、金文、小篆图片取自汉典 zdic.net 字形库，按原字形转成透明 PNG；缺金文者（晶、燕）只保留小篆阶段。
- 字卡里的字理解释按通行甲骨文字释撰写，供学习理解，不是扫描件转录。
- 本仓库用于个人学习与朋友间测试。字形素材的权利归原书 / 原站，若要公开传播或商用，需自行核实并取得授权；字体与图片的出处已在 `js/trace-data.js` 顶部注明。

## 真机自测清单

- 首页：二十五点阵、左右滑动切契、箭头按钮在 320×568 与 430×932 都不越界。
- 对局：交换、连消、步数递减、目标达成后弹出成文与字卡。
- 字卡：大字开关、卜辞释义、字源演变播放与保存。
- 进度：关掉页面再进，已解锁的契与已识字仍在。
- 分享：微信小游戏内分享带 `lv` 与 `step`，朋友点开直接进对应关卡。
